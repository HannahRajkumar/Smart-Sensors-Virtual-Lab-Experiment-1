Arduino Soil Moisture Sensor

Interactive Virtual Experiment · Circuit connection · Live sensor simulation

1. Aim

To study how soil moisture affects the analog output of a soil moisture sensor and simulate an Arduino-controlled LED and water pump.

Virtual hardware simulation No physical Arduino required

2. Virtual circuit and pin connections

Connect the sensor to Arduino analog input A0. The virtual pump relay is controlled by digital pin D8. The LED is controlled by pin D13.

Wire colours in this teaching diagram: red = 5V / control, black = GND, yellow = analog signal. The pump is represented as a relay-controlled load. A real pump requires a suitable external supply and driver/relay circuit; never power it directly from an Arduino pin.

6. Arduino program (for physical hardware)

const int sensorPin = A0;
const int ledPin = 13;
const int relayPin = 8;

void setup() {
  Serial.begin(9600);
  pinMode(ledPin, OUTPUT);
  pinMode(relayPin, OUTPUT);
}

void loop() {
  int sensorValue = analogRead(sensorPin);

  // Calibrate these values for your own sensor.
  int moisturePercent =
      map(sensorValue, 900, 300, 0, 100);
  moisturePercent =
      constrain(moisturePercent, 0, 100);

  Serial.print("Analog value: ");
  Serial.println(sensorValue);
  Serial.print("Moisture: ");
  Serial.print(moisturePercent);
  Serial.println("%");

  if (moisturePercent < 30) {
    digitalWrite(ledPin, HIGH);
    digitalWrite(relayPin, HIGH); // Adapt to relay module logic
  } else {
    digitalWrite(ledPin, LOW);
    digitalWrite(relayPin, LOW);
  }

  delay(1000);
}

The code above assumes an active-HIGH relay. Some relay modules are active-LOW; check the module specifications and change the logic if required.

Result

The virtual experiment shows that the simulated analog sensor reading decreases as soil moisture increases. When the estimated moisture falls below 30%, the Arduino logic switches ON the LED and pump relay; otherwise, both remain OFF.
